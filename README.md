# Ulf TV (Android TV)

En ren Android TV-spelare i Apple TV-stil byggd med Kotlin, Jetpack Compose och Media3 (ExoPlayer).

## Så får du ut en färdig .apk utan Android Studio
1. Skapa ett nytt repository på GitHub.
2. Ladda upp alla filer från den här mappen (viktigt att mappen `.github/workflows/build-apk.yml` kommer med).
3. Gå till fliken **Actions** på GitHub och vänta ~2 minuter tills bygget är grönt.
4. Klicka på bygget och ladda ner **UlfTV-Debug-APK** längst ner under *Artifacts*.
5. Packa upp och installera `app-debug.apk` på din Android TV!
